## Platform

web

## Stack

Next.js (App Router) + MDX, Tailwind, Docker на VPS2, образ собирается в GitHub Actions. Выбор заказчика 2026-10-25; PostgreSQL и Prisma появляются только в v2.

## Users

Главный ученик: менеджер, продавец или предприниматель без навыков программирования, который хочет делать сайты, документы, аналитику и прототипы через Claude Code так же, как это делает автор. Приходит с конкретной задачей («собрать лендинг», «разобрать ТЗ», «автоматизировать отчёт»), а не ради теории.

Второй ученик: разработчик, который уже пишет код и хочет освоить Claude Code и понять, как агенты устроены внутри. Модуль 1 рассчитан на первого, модули 2–4 на второго.

Языки аудитории: русский и английский первыми, испанский третьим.

## Product Purpose

Сайт learn.vdmitriev.com превращает открытые MIT-материалы по Claude Code и AI-инженерии в упорядоченные учебные треки с квизами, практикой и прогрессом на трёх языках. Цель v1: личный бренд автора и входящие обращения на консалтинг. Цель v2: платная подписка.

Успех v1: ученик проходит трек «Claude Code с нуля» от установки до собственного агента и пишет автору по почте или в Telegram.

## Positioning

Автор не программист, а продавец и менеджер, который построил через Claude Code реальные продукты (Camerata, Kinly, Fabulita, vdmitriev.com) и показывает путь, а не теорию. Это не список ссылок на GitHub, а порядок уроков с квизами и заданиями, которые проверяются локальным скриптом. Ученик в любой момент может позвать автора внедрить это у себя. На русском такого курса нет.

## Operating Context

Ученик учится за своим компьютером с открытым терминалом и Claude Code; читает урок, выполняет шаги, проходит квиз, клонирует репозиторий-шаблон задания и запускает проверку. Прогресс хранится в его браузере. Контакт с автором: почта и Telegram @prodmastermos. Вебинары встраиваются с внешних видеоплатформ.

## Capabilities and Constraints

- Треки → модули → уроки в MDX, три языка (ru, en, es), одинаковые slug во всех языках.
- Квизы из quiz.json, проверка на клиенте. Прогресс и результаты в localStorage с экспортом файлом.
- Практика: репозиторий-шаблон и детерминированный локальный чекер, самоотметка на сайте.
- Видео: универсальный компонент встраивания с белым списком провайдеров.
- v1 без аккаунтов, форм, сбора персональных данных и базы данных (152-ФЗ, VPS2 за рубежом). Никаких форм подписки и заявок: только ссылки на почту и Telegram.
- Уровни доступа PUBLIC / ACCOUNT / PREMIUM размечаются в контенте уже в v1, применяются в v2.
- Лицензии: контент только из MIT-источников с блоком авторства на каждом уроке; официальная дока Anthropic только короткими цитатами со ссылкой; источники без лицензии и под CC BY-NC-ND только ссылками.
- Не решено: бюджет перевода через LLM, публичный или приватный репозиторий.

Терминология: трек, модуль, урок, квиз, практика, прогресс. Claude Code, CLAUDE.md, хук, субагент, скил, MCP не переводятся.

## Product Principles

1. Показывать путь практика, а не пересказывать документацию: каждый урок ведёт к действию в терминале.
2. Честность источников: авторство и лицензия видны на каждом уроке, цитаты со ссылкой.
3. Сначала менеджер, потом разработчик: вводный модуль без предварительных знаний, глубина растёт по модулям.
4. Ничего не собирать о человеке без необходимости: прогресс живёт у ученика, контакт по его инициативе.
5. Три языка равноправны в интерфейсе; контент может отставать, и это честно показывается.
