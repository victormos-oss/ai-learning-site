# Требования по доступности (WCAG 2.2 AA)

Отчёт агента a11y-architect, 2026-10-25. Основа: brief.md, requirements.md.

**Критерий приёмки, который нужно добавить в requirements.md:** 0 серьёзных нарушений axe (critical и serious) на всех шаблонах, ручной проход с клавиатурой и NVDA по ключевым сценариям. Lighthouse a11y 100 не равен соответствию WCAG: он ловит около трети проблем.

## 1. Чеклисты

### 1.1 Сквозные (все страницы)
- `<html lang>` по локали маршрута (`ru`, `en`, `es`) из `params.locale`, не хардкодить.
- `hreflang`, переведённый уникальный `<title>` (2.4.2).
- Каркас: `header`, `nav aria-label`, один `main` с `id`, `footer`. Одинаковый порядок навигации (3.2.3, 3.2.4).
- Skip link первым в фокусе, виден при фокусе, переводится (2.4.1).
- Один `h1`, без пропуска уровней.
- Фокус: индикатор не тоньше 2 px, контраст 3:1, не перекрыт sticky-шапкой; `scroll-padding-top` (2.4.7, 2.4.11).
- Клавиатура: всё доступно, нет ловушек, порядок совпадает с визуальным, нет положительного `tabindex` (2.1.1, 2.1.2, 2.4.3).
- Цели нажатия не меньше 24x24, на мобильном 44x44 (2.5.8).
- Контраст: текст 4.5:1, крупный 3:1, границы и иконки 3:1, в обеих темах и во всех состояниях (1.4.3, 1.4.11).
- Смысл не только цветом: ошибки, верно/неверно, «пройдено» (1.4.1).
- Масштаб 200% и reflow на 320 px без горизонтальной прокрутки, кроме кода и таблиц; не блокировать `user-scalable`; `rem` (1.4.4, 1.4.10).
- Интервалы переопределяются без потери контента (1.4.12).
- `prefers-reduced-motion`: отключает параллакс, анимации появления, плавный скролл; анимация дольше 5 с имеет паузу (2.2.2). Хук `useReducedMotion`.
- Тултипы и меню: закрываются Esc, не исчезают при наведении (1.4.13).
- Ориентация не заблокирована (1.3.4), нет мерцания чаще 3 раз в секунду (2.3.1).
- После клиентской навигации перенести фокус на `h1` или `main` (`tabIndex={-1}`) и обновить live-регион.
- `prefers-color-scheme`, `prefers-contrast`, `forced-colors`: фокус через `outline`, не только `box-shadow`.

### 1.2 Лендинг
- Один `h1`, CTA с понятным именем, не «Узнать больше».
- Декоративные картинки `alt=""`, содержательные с `alt` на языке страницы.
- Текст поверх изображений: контраст на худшем участке, подложка.
- Секции с `aria-labelledby`. Карусели не использовать.

### 1.3 Список треков
- `ul/li`, карточка одна ссылка (растянутая псевдоэлементом), без вложенных интерактивов.
- Метаданные текстом, замок «премиум» с текстовой альтернативой.
- Фильтры: нативные `select`/чекбоксы с `label`, результат объявляется через live-регион.
- Пагинация: `nav aria-label`, `aria-current="page"`.

### 1.4 Страница урока
- Хлебные крошки, `h1`, оглавление `nav`, тело `article`, «назад/вперёд» с названиями уроков.
- Заголовки MDX с якорем, у якоря имя «Ссылка на раздел X».
- Строка до 70ch, межстрочный 1.5+, без выключки по ширине.
- Цитаты на другом языке: `<blockquote lang="en">`, внутристрочно `<span lang="en">` (3.1.2). Короткие англицизмы не размечать, фразы длиннее 2–3 слов размечать.
- Блок авторства текстом, ссылка «Оригинал на GitHub: learn-claude-code (MIT)».
- Внешние ссылки с пометкой, `rel="noopener"`.
- Таблицы: `caption`, `th scope`, прокручиваемая обёртка с `tabindex="0"`, `role="region"`, `aria-label`.
- Заметки «Важно», «Совет»: `aside` или `role="note"` с текстовым префиксом.
- Заблокированный урок: причина текстом, «Войти» это ссылка.
- «Отметить пройденным»: `aria-pressed` или чекбокс, результат объявляется.

### 1.5 Квиз
- Вопрос в `fieldset` с `legend`, варианты нативные radio или checkbox с `label`.
- «Вопрос 2 из 5» текстом.
- Кнопки нативные `button`; после «Далее» фокус на `legend` нового вопроса.
- Результат «Верно» или «Неверно, правильный ответ: B» в `role="status"` плюс иконка.
- Пояснение через `aria-describedby`. Итог в `role="status"`.
- Без таймеров. Код в вопросе отдельным блоком, не в `legend`.
- Не сбрасывать ответы при ошибке (3.3.7).

### 1.6 Прогресс по треку
- Чеклист `ul` со статусом текстом.
- Прогресс-бар: нативный `<progress>` с `aria-label` или `role="progressbar"` с `aria-valuenow/min/max/valuetext`. Видимый текст «7 из 17 уроков (41%)». Контраст заливки к дорожке 3:1.
- Не объявлять каждое изменение, только итог через `status`.

### 1.7 Формы
- Видимый `label` через `for/id`, placeholder не заменяет (3.3.2).
- `autocomplete`: `email`, `name`, `organization`, `tel` (1.3.5).
- `required` + текст «обязательное поле», формат заранее.
- Ошибки: у поля через `aria-describedby`, `aria-invalid`; сводка вверху с фокусом (3.3.1, 3.3.3).
- Не отключать кнопку как способ показать ошибку; `aria-busy`; успех в `role="status"`.
- Magic link / код: разрешить вставку и автозаполнение, `autocomplete="one-time-code"`, одно поле, без когнитивных тестов (3.3.8). Без капчи: honeypot и rate limit.
- Не просить дважды одни данные (3.3.7). Согласие на рассылку отдельный непредотмеченный чекбокс.
- Контакт для помощи в одном месте на всех страницах (3.2.6).

### 1.8 Личный кабинет
- Ориентиры, `nav` с `aria-current`. Таблицы с `th`. Статусы текстом.
- Меню пользователя по паттерну Disclosure или Menu Button (Radix).
- Истечение сессии: предупреждение и продление (2.2.1).
- Подтверждения: `alertdialog`, фокус на безопасной кнопке.

### 1.9 Расписание вебинаров
- `ul` или таблица с `caption`; `<time datetime>` с часовым поясом текстом («19:00 МСК (UTC+3)»).
- Даты через `Intl.DateTimeFormat`.
- «Добавить в календарь» с полным именем. Прошедшие отличаются текстом.

### 1.10 Переключатели языка и темы
- Язык: `nav aria-label="Язык"` со ссылками, у каждой `lang` и `hreflang`, имя на своём языке, `aria-current="true"`. Не `select` с автопереходом (3.2.2).
- Не менять язык автоматически без возврата; сохранять выбор.
- Тема: `button aria-pressed` с неизменным именем или радиогруппа (система, светлая, тёмная).
- Inline-скрипт до гидратации против вспышки темы. Обе темы проверяются на контраст отдельно.
- Иконки `aria-hidden`, имя в тексте или `aria-label`.

### 1.11 Три языка
- Корневой `lang` по локали, короткие коды.
- Английские цитаты и фразы внутри ru/es уроков с `lang="en"`. Код и команды без `lang` (`translate="no"`).
- Компонент `<Quote lang="en" cite>`; remark-плагин проверяет `lang` у цитат из доки; при импорте в ru/es цитаты из en-источника получают `lang="en"` автоматически.
- Непереведённый урок: контейнер `lang="en"` и плашка «пока только на английском».
- Шрифты с кириллицей и латиницей с диакритикой (á, é, ñ, ¿, ¡).
- Русский и испанский длиннее английского на 20–30%: кнопки и меню не обрезаются.
- `hyphens: auto` с корректным `lang`; проверить, что мягкие переносы (U+00AD) не читаются screen reader.
- Проверить NVDA и VoiceOver на смешанных страницах.

## 2. Как сделать доступными

### 2.1 Подсветка кода
- Две темы кода, каждый токен 4.5:1 к фону блока (комментарии часто проваливаются). Проверять скриптом по палитре.
- Shiki на сервере; не брать default-темы вслепую.
- Смысл не только цветом токена; в диффах знаки `+`/`-`.
- `pre` с `tabindex="0"`, `role="region"`, `aria-label="Код: python, файл agent.py"` (правило axe `scrollable-region-focusable`).
- Горизонтальный скролл внутри блока допустим (исключение 1.4.10).
- «Копировать»: нативная `button`, подтверждение в live-регионе, цель 24x24+.
- Номера строк: `user-select: none`, `aria-hidden` или CSS-счётчики.
- Название файла как `figcaption`. В `forced-colors` фон токенов не исчезает.

### 2.2 Mermaid SVG
- Рендер при сборке в статический SVG.
- `<figure>` + `<figcaption>`; у SVG `role="img"`, `aria-labelledby`, внутри `<title>` и `<desc>`. Mermaid `accTitle` и `accDescr` дают их.
- Для сложных диаграмм видимая текстовая версия (список шагов или таблица связей) в `details` (1.1.1, 1.3.1).
- `accTitle/accDescr` и подписи переводятся с уроком; линтер на импорте требует их у каждого блока ```mermaid.
- Контраст: текст в узлах 4.5:1, линии 3:1, типы узлов не только цветом. Свои `themeVariables` для светлой и тёмной.
- `viewBox`, `max-width: 100%`; при 320 px фокусируемый скролл или «Открыть крупно».
- Без `click` внутри диаграмм.
- Статичные картинки из источников: `alt` с содержанием, текст со скриншотов в тексте.

### 2.3 Видео
- Без автоплея и автозвука (1.4.2, 2.2.2). Фоновое видео только без звука, с паузой, при reduced motion постер.
- Субтитры на языке страницы, вычитанные (1.2.2).
- Скринкасты без озвучки: транскрипция со снимками экрана (1.2.3, 1.2.5). Транскрипт под видео в `details`.
- Живые вебинары: субтитры в реальном времени или запись с субтитрами и честная пометка (1.2.4).
- Критерии выбора платформы: клавиатура в плеере, загрузка субтитров. iframe с `title`, `loading="lazy"`, `youtube-nocookie.com`.
- Фасад: обложка и `button` «Воспроизвести видео: название», по клику iframe и фокус в плеер.
- Tab выходит из iframe.

### 2.4 Квиз (реализация)
```html
<form>
  <fieldset>
    <legend>Какая команда запускает сессию Claude Code?</legend>
    <label><input type="radio" name="q1" value="a"> claude</label>
  </fieldset>
  <button type="submit">Проверить</button>
  <div role="status" aria-live="polite" id="quiz-result"></div>
</form>
```
- Live-регион в DOM заранее, пустой. `role="status"` для результата, `role="alert"` только для критичных ошибок.
- Фокус остаётся на кнопке, результат через live-регион; на итоговой странице фокус на заголовок. Не дублировать.
- Верно/неверно текстом внутри `label` и иконкой.
- Скрытые вопросы убирать из дерева (`hidden`), не `aria-hidden`.
- quiz.json содержит `explanation`, при картинках `alt`; схема валидируется в CI.

### 2.5 Прогресс-бар
- Нативный `<progress>` предпочтителен. Либо `<div role="progressbar" aria-label="Прогресс по треку" aria-valuemin="0" aria-valuemax="17" aria-valuenow="7" aria-valuetext="7 из 17 уроков">`.
- `aria-valuetext` локализован через `Intl.PluralRules` (1 урок, 2 урока, 5 уроков).
- Без `aria-live` на полосе. Неопределённый прогресс это `role="status"` + текст.
- Анимация заполнения отключается при reduced motion.

## 3. Готовые компоненты и свои

| Компонент | Рекомендация |
|---|---|
| Диалоги, alertdialog | Radix Dialog / AlertDialog |
| Меню пользователя | Radix DropdownMenu |
| Tabs (Код / Объяснение) | Radix Tabs |
| Accordion, FAQ, оглавление | нативные `details/summary` или Radix Accordion |
| Tooltip | Radix Tooltip, лучше избегать |
| Select, Combobox | нативный `select`, иначе React Aria |
| Toast | Radix Toast или свой `status` |
| Radio, Checkbox, Switch | нативные для квиза и чеклиста |
| Toggle темы | Radix Toggle / ToggleGroup |
| Progress | нативный `<progress>` |
| Формы | React Hook Form + Zod, ARIA ошибок свои |
| Дата (если будет) | React Aria DatePicker |
| Видео | платформенный iframe с фасадом |

Radix по умолчанию, React Aria только для Select/ComboBox/DatePicker. Не смешивать две библиотеки для одного паттерна.

**Своё:** каркас, skip link, крошки, пагинация; квиз на нативных элементах; список уроков и чеклист; блок кода; обёртка Mermaid, `<Quote lang>`, заметки; переключатели языка и темы; общий `<Announcer>` в layout; обёртка поля `Field` (label, hint, error, id-связи); карточки и расписание.

**Не писать самим:** модалки, меню, комбобоксы, календари, ловушки фокуса, расчёт контраста вручную.

## 4. Автоматические проверки для CI

Автотесты находят 30–40% проблем.

### 4.1 Статика
- `eslint-plugin-jsx-a11y` strict, падает сборка.
- Линтер контента: `accTitle`/`accDescr` у mermaid, `alt` у img, нет ссылок «здесь», нет пропусков заголовков, цитаты из en в ru/es с `lang="en"`, `explanation` в quiz.json.
- Скрипт контраста токенов обеих тем и тем кода.
- `stylelint` против `outline: none` без замены.

### 4.2 axe в Playwright (`@axe-core/playwright`)
- Теги `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22aa`, `best-practice`.
- Матрица: каждый шаблон × 3 локали × 2 темы × 2 вьюпорта (1440 и 375). Шаблоны: лендинг, треки, урок (код, Mermaid, видео, цитата), урок с квизом, вход, подписка, консалтинг, кабинет, расписание, премиум-урок заблокирован, 404, ошибка.
- Интерактивные состояния: открытое меню, модалка, квиз после ответа, форма с ошибками, раскрытые `details`.
- critical и serious падают CI; moderate и minor в отчёт, затем блок. Исключения по allowlist с причиной и датой.
- Правила: `color-contrast`, `label`, `image-alt`, `svg-img-alt`, `link-name`, `button-name`, `html-has-lang`, `valid-lang`, `heading-order`, `landmark-one-main`, `region`, `aria-valid-attr`, `scrollable-region-focusable`, `nested-interactive`, `target-size`, `frame-title`, `video-caption`, `duplicate-id-aria`.
- `color-contrast` incomplete в тёмной теме смотреть вручную.

### 4.3 Playwright поведенческие
- Полный проход Tab: первый фокус на skip link, видимый фокус у каждого элемента, нет ловушек, порядок по DOM.
- Skip link переносит фокус в `main`. Модалка: Esc, возврат фокуса, Tab не уходит.
- Квиз только клавиатурой; `role=status` содержит ожидаемый текст.
- Формы: пустая отправка даёт `aria-invalid`, `aria-describedby` на существующий узел, фокус на сводке; успех в `status`.
- Смена маршрута: фокус на заголовке, `document.title` обновился.
- Язык: URL, `html[lang]`, `hreflang`, плашка fallback с `lang="en"`.
- Тема сохраняется, нет вспышки, `aria-pressed` корректен.
- `emulateMedia({ reducedMotion: 'reduce' })`: `getAnimations()` пуст, нет автоплея.
- Reflow 320x256: `scrollWidth <= clientWidth` кроме кода и таблиц.
- Интервалы 1.4.12 через `addStyleTag`: нет обрезанного текста.
- Нет `video[autoplay]`, у iframe `title`, у фасада имя, `track[kind=captions]` при своём video.
- У каждого Mermaid `svg` в `figure` `role="img"` и `title`/`desc`.
- `forcedColors: 'active'` скриншоты.
- `toMatchAriaSnapshot` для квиза, прогресса, навигации, переключателей.
- Bounding box интерактивов не меньше 24x24.

### 4.4 Lighthouse CI
- Лендинг, треки, урок, по одной на локаль, мобильный профиль.
- accessibility 100 как барьер, performance 90+, best-practices и SEO 90+.
- Утверждения: `color-contrast`, `image-alt`, `label`, `html-has-lang`, `meta-viewport`, `target-size`, `link-name`, `document-title`, `hreflang`, `is-crawlable`.
- CLS < 0.1, INP < 200 мс.

### 4.5 Дополнительно
- `html-validate`: дубли id, вложенность, `lang`.
- Визуальные регрессии на 320, 768, 1024, 1440 для фокуса, ошибок, обеих тем.
- Гейты: PR падает при axe/Playwright a11y; Lighthouse CI в отчёт PR и блок на main; ночной прогон по 3 локалям.
- Хелпер `expectNoA11yViolations(page, opts)` и projects в `playwright.config` (ru-light, en-dark, es-mobile).

### 4.6 Ручная проверка перед релизом
- NVDA + Firefox/Chrome: урок (английская цитата английским голосом), квиз, вход, подписка, смена языка и темы.
- VoiceOver + Safari и TalkBack.
- Только клавиатура; 200% и 400%; Windows High Contrast; Voice Control (2.5.3 Label in Name).
- Субтитры и транскрипты: точность.
- Перевод `aria-label`, `alt`, `title`, ошибок и live-текстов на ru/es.
- Заявление о доступности на трёх языках с контактом.

## 5. Пять частых ошибок таких сайтов

1. **Код и диаграммы недоступны**: серые комментарии, `pre` без фокуса, Mermaid без `title/desc`. Решение: разделы 2.1 и 2.2, линтер на импорте.
2. **Квиз только на цвете и без объявления результата**. Решение: нативные input, live-регион, текст.
3. **Неправильные `lang`**: хардкод, нет `lang` у цитат, переключатель как `select`. Решение: раздел 1.11, тесты.
4. **Фокус в SPA-навигации и `outline: none`**, липкая шапка закрывает фокус, модалки без возврата. Решение: перенос фокуса на `h1`, `scroll-padding`, Radix.
5. **Формы и вход с ловушками**: placeholder вместо label, ошибки только красным, код нельзя вставить, успех только в toast. Решение: раздел 1.7, компонент `Field`.
