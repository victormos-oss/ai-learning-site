## Вопрос

> Как превратить открытые материалы по Claude Code и AI-инженерии в многоязычный учебный продукт, который приводит лиды сейчас и продаётся по подписке позже?

## Что значит «готово» (первая версия)

1. Трек «Claude Code с нуля» на ru/en/es: уроки, квизы, прогресс.
2. Первый модуль открыт, остальное за аккаунтом; флаг премиум выдаётся вручную.
3. Формы сбора лидов на каждой странице трека.
4. Практика в Claude Code с автопроверкой.
5. Раздел видео и вебинаров.
6. Лицензии соблюдены, авторство указано.
7. Lighthouse 90+, пройден impeccable audit.
8. Повторяемый импорт с diff.

## Подход

1. Фаза 2: архитектура пайплайна (источник → MDX → БД), схема БД, модель сущностей, дизайн-направление, доступность.
2. Каркас: Next.js App Router + MDX + Prisma + PostgreSQL, i18n на три языка, рендер Mermaid и кода, Docker для VPS2.
3. Импорт первого трека, квизы, глоссарий терминов, перевод после подтверждения бюджета.
4. Аккаунты, прогресс, премиум-флаг, формы лидов.
5. Практика в Claude Code: задания с проверяемым результатом.
6. Видео-раздел, лендинг, SEO, impeccable audit, деплой на VPS2.

## Результат

**Продукт:** сайт на Next.js в Docker на VPS2, своя PostgreSQL.
**Аудитория:** разработчики и менеджеры, ru/en/es.

## Ограничения и риски

- Перевод через LLM платный: только после «да», сначала оценка токенов.
- У learn-claude-code нет квизов: писать самим, это время.
- Терминология на трёх языках: глоссарий с первого урока.
- Источники живые: импорт с diff, иначе контент устареет.
- Биллинга в v1 нет: премиум выдаётся вручную, при росте нужна вторая итерация.

## Явно вне объёма

- Собственный видеохостинг.
- Мобильное приложение.
- Контент из репозиториев без лицензии.
