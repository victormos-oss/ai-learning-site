## Обновление каталога

- Перед каждым `content:import --apply` обновлять commit и дату в этом файле (скрипт пишет их в `sources.lock.json`, каталог сверять с ним).
- При добавлении источника: запись по этому шаблону, строка в `sources.yaml`, проверка лицензии до импорта.
- Персданных нет ни в одном источнике, тегов соответствия не требуется.
