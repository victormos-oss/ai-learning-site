## Критерии успеха первой версии

Результат принимается, если:

1. Опубликован трек «Claude Code с нуля» на трёх языках (ru, en, es): текстовые уроки, квизы, прогресс ученика в браузере.
2. Весь контент открыт. Уровни доступа (PUBLIC, ACCOUNT, PREMIUM) размечены в контенте уже сейчас, чтобы в v2 включить фримиум без переразметки.
3. Контакт для консалтинга: ссылка на почту и Telegram на каждой странице трека, без форм и сбора данных.
4. Практические задания выполняются в Claude Code, результат проверяется локальным скриптом в репозитории задания; ученик отмечает выполнение сам, отметка хранится в браузере.
5. Раздел «Видео и вебинары» со встраиванием и расписанием.
6. Лицензии соблюдены: контент только из MIT-репозиториев и официальной доки Anthropic (цитатами со ссылкой), авторство указано на каждом уроке.
7. Lighthouse 90+ на главной и странице урока, пройден `/impeccable audit`.
8. Скрипт импорта запускается повторно и показывает diff с источником.
9. Доступность: 0 нарушений уровня critical и serious в axe на всех шаблонах страниц, ручной проход с клавиатурой и NVDA по ключевым сценариям (детали в accessibility.md).

## Объём

**В объёме первой версии:**
- Контент-пайплайн: markdown источников → MDX, структура Трек → Модуль → Урок.
- Перевод трека «Claude Code с нуля» на ru и es (источник en; у learn-claude-code есть zh и ja как ориентир).
- Квизы: формат quiz.json из ai-engineering-from-scratch как стандарт; для learn-claude-code квизы пишем сами.
- Прогресс и результаты квизов в браузере (localStorage), экспорт и импорт файлом.
- i18n на три языка для интерфейса и контента.
- Видео: универсальный компонент встраивания с белым списком провайдеров, страница расписания вебинаров.
- Лендинг и SEO на трёх языках.
- Деплой на VPS2 через GHCR, без БД.

**В объёме следующих версий (v2):**
- Аккаунты, прогресс в БД, фримиум (первый модуль открыт, остальное за аккаунтом), премиум-флаг, формы лидов. Требует решения по 152-ФЗ и PostgreSQL.
- Трек «AI-инженерия» из ai-engineering-from-scratch: 542 урока, 392 квиза, 20 фаз. Переводить по фазам, начиная с 13–16 (агенты, MCP, мультиагентность).
- Биллинг: ЮKassa для РФ и Paddle или Stripe для мира.
- Практика с токенами и серверной записью результата (вариант A из architecture.md), затем GitHub Actions + OIDC.
- Трек «Основы CS» по карте OSSU как ссылки на внешние курсы.

**Вне объёма:**
- Собственный хостинг видео и стриминг.
- Мобильное приложение.
- Сертификаты и проверка домашних заданий человеком.
- Форум и комьюнити.
- Контент из репозиториев без лицензии (claude-code-everyone-course) и под CC BY-NC-ND (awesome-claude-code): только ссылки.

## Допущения и ограничения

- Платные действия (перевод через LLM, покупка домена, сервисы) только после явного «да» заказчика.
- Контент из MIT-репозиториев перерабатывается и переводится с указанием авторства и ссылкой на оригинал.
- Деплой на VPS2 по правилам проекта: ревью кодом и безопасностью до сборки, после деплоя проверка HTTP 200, логин и пароль присылаются заказчику.
- UI строится по скилам impeccable + design-taste-frontend; стиль и палитру выбираем в фазе 2, если заказчик не задаст свои.
- Сборка Next.js на VPS2 возможна; на VPS1 не хватает памяти.
